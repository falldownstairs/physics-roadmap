================================================================================
                    LATEX RENDERING CHEATSHEET FOR LESSONS
================================================================================

This guide shows how to properly format LaTeX in lesson files (.js) for 
rendering in the frontend. All LaTeX must be wrapped in $ or $$ delimiters.

================================================================================
                              BASIC SYNTAX
================================================================================

Inline Math (small, within text):
  $x = 5$                           → x = 5
  $E = mc^2$                        → E = mc²

Display Math (large, centered):
  $$F = ma$$                        → F = ma (centered, larger)
  $$\\int_0^\\infty e^{-x} dx$$     → ∫₀^∞ e⁻ˣ dx (centered, larger)

================================================================================
                           TEXT FORMATTING
================================================================================

Regular Text (use \\text{}):
  $\\text{velocity}$                → velocity (upright text)
  $\\text{constant acceleration}$   → constant acceleration

Bold Text:
  $\\textbf{Force}$                 → Force (bold)
  $\\mathbf{F}$                     → F (bold math symbol)

Italics (default for math):
  $v$                               → v (italic)
  $acceleration$                    → acceleration (italic, spacing issues)
  $\\textit{word}$                  → word (italic text)

================================================================================
                          MATHEMATICAL SYMBOLS
================================================================================

Greek Letters:
  $\\alpha$                         → α
  $\\beta$                          → β
  $\\gamma$                         → γ
  $\\Delta$                         → Δ (capital)
  $\\delta$                         → δ (lowercase)
  $\\theta$                         → θ
  $\\omega$                         → ω
  $\\pi$                            → π
  $\\sigma$                         → σ

Special Symbols:
  $\\infty$                         → ∞
  $\\partial$                       → ∂ (partial derivative)
  $\\nabla$                         → ∇ (del/gradient)
  $\\pm$                            → ±
  $\\times$                         → ×
  $\\cdot$                          → · (dot product)
  $\\approx$                        → ≈
  $\\neq$                           → ≠
  $\\leq$                           → ≤
  $\\geq$                           → ≥

================================================================================
                        FRACTIONS & POWERS
================================================================================

Fractions:
  $\\frac{a}{b}$                    → a/b (stacked)
  $\\frac{\\Delta x}{\\Delta t}$    → Δx/Δt
  $\\frac{1}{2}mv^2$                → ½mv²

Powers (Superscripts):
  $x^2$                             → x²
  $e^{-x}$                          → e⁻ˣ
  $v^{2}$                           → v²
  $10^{-3}$                         → 10⁻³

Subscripts:
  $v_0$                             → v₀
  $x_i$                             → xᵢ
  $\\text{v}_f$                     → vf (subscript with text)

Combined:
  $v_0^2$                           → v₀²
  $x_{\\text{initial}}$             → xᵢₙᵢₜᵢₐₗ

================================================================================
                          CALCULUS NOTATION
================================================================================

Derivatives:
  $\\frac{dx}{dt}$                  → dx/dt
  $\\frac{d^2x}{dt^2}$              → d²x/dt²
  $\\frac{dv}{dt}$                  → dv/dt

Integrals:
  $\\int v \\, dt$                  → ∫v dt
  $\\int_0^t a \\, dt$              → ∫₀ᵗ a dt
  $\\int_{-\\infty}^{\\infty}$      → ∫₋∞^∞

Note: Use \\, for spacing before dt, dx, etc.

Limits:
  $\\lim_{x \\to 0}$                → lim(x→0)
  $\\lim_{t \\to \\infty} f(t)$     → lim(t→∞) f(t)

================================================================================
                          VECTORS & MATRICES
================================================================================

Vectors:
  $\\vec{v}$                        → v⃗ (arrow)
  $\\mathbf{F}$                     → F (bold)
  $\\hat{i}$                        → î (unit vector)

Vector Operations:
  $\\vec{a} \\cdot \\vec{b}$        → a⃗·b⃗ (dot product)
  $\\vec{a} \\times \\vec{b}$       → a⃗×b⃗ (cross product)

Matrices:
  $$\\begin{bmatrix} a & b \\\\ c & d \\end{bmatrix}$$  → [a b]
                                                           [c d]

================================================================================
                        EQUATIONS & ALIGNMENT
================================================================================

Single Equation:
  $$v_f = v_i + at$$                → vf = vi + at (centered)

Multiple Equations (aligned):
  $$\\begin{align*}
  v_f &= v_i + at \\\\
  x &= v_i t + \\frac{1}{2}at^2
  \\end{align*}$$

Note: Use & for alignment point, \\\\ for new line, * to hide numbering

================================================================================
                          SPECIAL FORMATTING
================================================================================

Square Roots:
  $\\sqrt{x}$                       → √x
  $\\sqrt{2}$                       → √2
  $\\sqrt[3]{8}$                    → ³√8 (cube root)

Absolute Value:
  $|x|$                             → |x|
  $\\left| \\frac{a}{b} \\right|$   → |a/b| (auto-sizing)

Parentheses (auto-sizing):
  $\\left( \\frac{a}{b} \\right)$   → (a/b) with proper sizing
  $\\left[ x^2 \\right]$            → [x²] with proper sizing
  $\\left\\{ a, b \\right\\}$       → {a, b} with proper sizing

Spacing:
  $a\\,b$                           → a b (thin space)
  $a\\;b$                           → a  b (medium space)
  $a\\quad b$                       → a    b (large space)

================================================================================
                          COMMON PHYSICS FORMULAS
================================================================================

Kinematics:
  $v_f = v_i + at$
  $$\\Delta x = v_i t + \\frac{1}{2}at^2$$
  $$v_f^2 = v_i^2 + 2a\\Delta x$$

Newton's Laws:
  $$\\sum F = ma$$
  $$F = G\\frac{m_1 m_2}{r^2}$$

Energy:
  $$KE = \\frac{1}{2}mv^2$$
  $$PE = mgh$$
  $$E = mc^2$$

Waves:
  $$v = f\\lambda$$
  $$T = \\frac{1}{f}$$

================================================================================
                          COMMON MISTAKES
================================================================================

❌ WRONG:                           ✅ CORRECT:
--------------------------------    --------------------------------
$velocity$                          $\\text{velocity}$
$Distance$                          $\\text{Distance}$
$$\int v dt$$  (missing \\)         $$\\int v \\, dt$$
$v_initial$                         $v_{\\text{initial}}$ or $v_i$
$delta x$                           $\\Delta x$
$1/2 m v^2$  (no LaTeX)             $\\frac{1}{2}mv^2$
$$\\$$int$$  (double $$)            $$\\int$$

================================================================================
                          QUESTION TYPES & PARAMETERS
================================================================================

Multiple Choice Question:
  {
    type: 'multiple-choice',
    question: "Question text with $\\text{LaTeX}$",
    options: ["Option 1", "Option 2", "Option 3", "Option 4"],
    correctAnswer: 0,  // Index of correct option (0-based)
    explanation: "Explanation with $\\text{LaTeX}$"
  }

Math Input Question:
  {
    type: 'math-input',
    question: "Question text with $\\text{LaTeX}$",
    mathAnswer: "\\frac{dv}{dt}",  // Expected LaTeX answer
    answerRange?: 0.1,  // Optional: acceptable range (e.g., ±0.1)
    explanation: "Explanation with $\\text{LaTeX}$"
  }

Word Question:
  {
    type: 'word-question',
    question: "Question text",
    answer: "expected answer",
    explanation: "Explanation with $\\text{LaTeX}$"
  }

Answer Range Examples:
  - No range specified: exact match required (default tolerance 0.0001)
  - answerRange: 0.1 → answer must be within ±0.1 of correct value
  - answerRange: 0.5 → answer must be within ±0.5 of correct value
  - answerRange: 1 → answer must be within ±1 of correct value

Example with answer range:
  {
    type: 'math-input',
    question: "Calculate the acceleration (in $\\text{m/s}^2$) of an object with mass $5\\text{ kg}$ under a force of $20\\text{ N}$.",
    mathAnswer: "4",
    answerRange: 0.1,  // Accept answers between 3.9 and 4.1
    explanation: "Using Newton's second law: $$a = \\frac{F}{m} = \\frac{20}{5} = 4 \\text{ m/s}^2$$"
  }

================================================================================
                          EXAMPLE LESSON FILE
================================================================================

module.exports = {
  id: "101",
  title: "Introduction to Kinematics",
  videos: [
    {
      videoId: "abc123",
      questions: [
        {
          type: 'multiple-choice',
          question: "What is the SI unit of $\\text{velocity}$?",
          options: [
            "$\\text{meters}$ ($\\text{m}$)",
            "$\\text{meters per second}$ ($\\text{m/s}$)",
            "$\\text{meters per second squared}$ ($\\text{m/s}^2$)",
            "$\\text{seconds}$ ($\\text{s}$)"
          ],
          correctAnswer: 1,
          explanation: "$\\text{Velocity}$ is defined as the rate of change of $\\text{position}$ with respect to $\\text{time}$: $$v = \\frac{\\Delta x}{\\Delta t}$$ Therefore, its units are $\\text{m/s}$."
        },
        {
          type: 'math-input',
          question: "Express $\\text{acceleration}$ as the derivative of $\\text{velocity}$.",
          mathAnswer: "\\frac{dv}{dt}",
          explanation: "$\\text{Acceleration}$ is the time derivative of $\\text{velocity}$: $$a = \\frac{dv}{dt}$$"
        },
        {
          type: 'math-input',
          question: "Calculate the final velocity (in $\\text{m/s}$) after $5\\text{ s}$ with initial velocity $10\\text{ m/s}$ and acceleration $2\\text{ m/s}^2$.",
          mathAnswer: "20",
          answerRange: 0.5,  // Accept 19.5 to 20.5
          explanation: "Using the kinematic equation: $$v_f = v_i + at = 10 + (2)(5) = 20 \\text{ m/s}$$"
        }
      ]
    }
  ]
};

================================================================================
                              TESTING YOUR LATEX
================================================================================

1. Always wrap LaTeX in $ or $$
2. Use \\text{} for regular words
3. Test your lesson in the frontend to verify rendering
4. Check browser console for LaTeX parsing errors
5. For complex equations, test in an online LaTeX editor first

Online LaTeX editors for testing:
- https://www.codecogs.com/latex/eqneditor.php
- https://latexeditor.lagrida.com/
- https://www.overleaf.com/
